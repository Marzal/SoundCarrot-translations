# SoundCarrot Translation Guide

## Voice

SoundCarrot should feel like a friendly parent recommending something genuinely good to another parent.

The tone is:

- friendly
- informal
- warm
- playful
- clear
- occasionally silly
- never corporate or sales-heavy

The site is for families, so translations should be comfortable for parents while remaining approachable to children.

## Natural language over literal translation

The English wording is a reference for meaning, not a template that must be copied word-for-word.

If a direct translation sounds unnatural in the target language, use the natural expression a native speaker would actually use.

This is particularly important for:

- headings
- buttons
- short UI labels
- jokes and playful copy
- the FAQ
- the homepage
- phrases involving the SoundCarrot brand

## SoundCarrot terminology

Keep these names unchanged unless there is an established local convention:

- SoundCarrot
- Team Carrot
- Yoto
- podcast/show names
- names of people and organisations

The terms `Story` and `Episodic` describe the two podcast formats used by SoundCarrot. Translate them naturally for the target language, while preserving the distinction between a serialised story that should generally be listened to in order and an episodic show that can be heard in any order.

## Placeholders

Never translate, rename or remove placeholders.

Examples:

```text
{country}
{age}
{count}
{email}
{query}
{title}
{topics}
{year}
{seasonWord}
{n}
{plural}
```

A placeholder can move within a sentence if the grammar of the target language requires it, but the placeholder itself must remain exactly the same.

## UI strings

Short strings may appear in buttons, navigation, labels, filters, tooltips or other interface elements.

Keep these concise where possible. A translation that is grammatically correct but dramatically longer than the English can make the interface awkward.

## Playful language

SoundCarrot sometimes uses playful language around the carrot/veg patch theme. If a literal translation sounds odd in the target language, preserve the playful intent rather than translating each word literally. You know your own language better than we do :) 

## When something doesn't make sense

If you cannot determine what a string means from the English text and its section, don't guess confidently.

Raise an issue or ask the SoundCarrot team for context. A question is much easier to fix than a translation that looks correct but means something different in the interface.
